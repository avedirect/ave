# AVE Direct — SEO/GEO оптимизация блога

База: `seo-geo-promotion` (статьи + GEO) + `site-factory` rules `05-seo-geo` и `06-blog-visp`.
Сайт: https://avedirect.ru/ · CPT: `articles` · REST base: `/wp-json/wp/v2/articles` ·
рубрики: `articles-cat` (Яндекс Директ = 28, Маркетинг = 35 и др.).

## Когда применять

- Написать / переписать / SEO-оптимизировать статью или пачку статей блога.
- Массово починить Title и Description в Yoast.
- Проверить, что формат совпадает с рабочими статьями (обложка в середине + CTA).
- Довести **светофоры Yoast до зелёных** (SEO + Readability) и снять orphaned — см. `YOAST-GREEN.md`.

## Доступы (не светить в чат)

- Application Password WordPress + cookie `beget=begetok` на Beget.
- Yoast meta через REST `meta._yoast_*` **не пишется** — только Bulk Editor API ниже.

## Формат живой статьи на сайте (обязательно сохранить)

1. Вступление с **жирным названием темы** и 1–2 предложениями «о чём материал».
2. H2-блоки; **первое предложение под каждым H2 — прямой ответ**.
3. В середине: `<figure class="wp-block-image size-large ave-direct-article-cover">…</figure>` + CTA-кнопка медиаплана (`md-main-color-btn2`, `popupopen="order-popup"`).
4. Перед выводом: `[banner]`.
5. Вывод + мягкий CTA.
6. Обложки — стиль AVE DIRECT (белый фон, чёрный заголовок, красный `#e31e24`, 3D-метафора, логотип справа сверху).

## SEO-каркас каждой статьи (ВИСП + GEO)

| Элемент | Правило |
|---|---|
| Title (Yoast) | ≤ ~65–70 симв.: ключ + выгода/конфликт + `\| AVE Direct` или без бренда, если не влезает. Без длинного слогана сайта. |
| Description | 140–160 симв.: прямой ответ + кому полезно + конкретика. Не копировать title и не подставлять слоган агентства. |
| H1 | = заголовок записи; один; с ключом. |
| Первый абзац | Прямой ответ 40–60 слов на главный вопрос статьи. |
| H2 | Вопросы/подзапросы; ответ — первым предложением. |
| «Коротко» | После вступления блок `<p><strong>Коротко:</strong> …</p>` с цифрами/шагами (GEO/tldr). |
| FAQ | 3–4 вопроса в конце перед выводом + видимый HTML (не только скрытый). |
| Перелинковка | ≥2 внутренних ссылки на релевантные articles/услуги. |
| CTA | Существующая кнопка медиаплана + `[banner]`. |
| Alt обложки | Описательный, с ключом темы. |
| Факты | Не выдумывать цифры клиентов; опираться на принципы Директа/маркетинга из `yandex-direct-offers`. |

### ВИСП (из site-factory)

- **Выгода** в title и первом абзаце.
- **Интрига** — конфликт/ошибка мышления.
- **Срочность** — мягко (обучение стратегии, бюджет недели).
- **Причастность** — «ваша кампания / ваша ниша».
- Обещание заголовка раскрыто в тексте.

## API: править Title / Description

Список и фильтр «нужно улучшить»:

```http
GET /wp-json/yoast/v1/bulk_editor/posts?content_type=articles&per_page=100&page=1
GET ...&needs_improvement[]=seo_title&needs_improvement[]=meta_description
```

Обновление батчами **по 10** (батчи 40+ часто дают HTTP 400):

```http
POST /wp-json/yoast/v1/bulk_editor/update_search
Content-Type: application/json

{
  "items": [
    {
      "id": 123,
      "seo_title": "Короткий SEO-title | AVE Direct",
      "meta_description": "Уникальное описание 140–160 символов с ответом на интент."
    }
  ]
}
```

Скрипт массового прогона: `scripts/bulk_yoast.py` (env `WP_AUTH=login:app-password`).

Контент статьи:

```http
POST /wp-json/wp/v2/articles/{id}
{ "content": "<html>...", "status": "publish" }
```

Авторизация: Basic (логин + application password) + Cookie `beget=begetok`.

## Пайплайн массовой оптимизации

1. Снять `needs_improvement` или полный список articles.
2. Для каждой: из `title` + первого абзаца content собрать уникальные seo_title и meta_description.
3. POST `update_search` батчами; логировать failures.
4. Для приоритетных URL (свежие, Яндекс Директ, маркетинг): дописать Коротко, FAQ, прямые ответы, перелинковку.
5. Проверить 3–5 URL в браузере: title в `<title>`, description в meta, CTA и обложка на месте.
6. Отчёт: сколько обновлено мета / сколько переписано тело / что осталось.

## Шаблоны сниппетов

**Title:** `{Ключ}: {выгода или конфликт} | AVE Direct`  
Примеры: `Одна цель в Директе: почему микроцели ломают обучение | AVE Direct`

**Description:** `{Прямой ответ}. {Что сделать читателю за 1 шаг}.`  
Пример: `Стратегия учится на том, что вы назвали целью. Оставьте одну цель «заявка» или CRM — и две недели не возвращайте микроцели.`

## Антипаттерны

- Title = «Заголовок - Контекстная реклама Яндекс Директ и Квизмаркетинг…» (полный слоган сайта).
- Description = заголовок + слоган или одна шаблонная фраза на десятки статей («роли, показатели, ошибки…»).
- Заполнить SEO Title/Description через Bulk и **не задать Focus keyphrase** → в редакторе SEO останется красным.
- Focus keyphrase = весь H1 (типично «Школа управления») вместо запроса 2–4 слова.
- Переписывать все 2700+ текстов за один заход без батчей и отчёта.
- Убирать CTA / `[banner]` / класс обложки.
- Выдуманные кейсы и цифры CPL без источника.

## Светофоры Yoast (кратко)

- **SEO** и **Readability** — разные проверки. Зелёный эталон: ключ `обучение стратегии` в статье про частые правки.
- Без Focus keyphrase Bulk-метатеги не «зеленят» SEO. Ключ API `update_search` не пишет — только сайдбар Yoast / meta `_yoast_wpseo_focuskw`.
- Серый в списке ≈ `notAnalyzed` (тысячи articles) — открыть/сохранить запись после правок.
- Orphaned (Premium) = нет **входящих** внутренних ссылок; чинится перелинковкой с других articles.
