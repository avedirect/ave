# Фотографии секций

Положите сюда 9 картинок из референс-сетки 3×3 (слева→направо, сверху→вниз).
Они подхватятся автоматически (JS проверяет загрузку; если файла нет — секция
выглядит как сейчас, с canvas-анимацией).
