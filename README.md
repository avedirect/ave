# Fir Design — Ремонт квартир «под ключ» в Москве

Лендинг компании по ремонту квартир под ключ (экспорт страницы `/remont` с Tilda).
Взят за основу как реальный код, стили и контент.

## Бренд и смыслы

- **Оффер:** ремонт квартир под ключ в Москве за 60 дней, фикс. цена, гарантия до 3 лет
- **Телефон:** +7 (926) 223 06 60
- **Адрес:** Москва, ул. Дорожная, д. 50 · ежедневно 8:00–19:00
- **Ключевые блоки:** квиз-калькулятор стоимости, преимущества (фикс-смета,
  неустойка 0,1%/день, фото-/видеоотчёты, гарантия 3 года, экономия до 15%),
  дизайн-проект, портфолио, этапы работ (4 шага), отзывы, FAQ, формы заявок

## Структура

```
.
├── index.html              # главная (копия страницы /remont)
├── page148101286.html      # оригинальный файл страницы /remont (Tilda)
├── 404.html
├── .htaccess               # роутинг Apache (/remont → page148101286.html)
├── css/                    # стили Tilda (грид, формы, блоки, шрифты)
├── js/                     # скрипты Tilda (квиз, формы, анимации, галерея)
├── images/                 # изображения, иконки, фото проектов
├── files/                  # доп. содержимое страницы
├── robots.txt / sitemap.xml
└── readme.txt              # оригинальная инструкция Tilda по выгрузке
```

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Статический хостинг (GitHub Pages, Netlify и т.п.) отдаёт `index.html`.
На Apache работает и человекочитаемый адрес `/remont` через `.htaccess`.

## Заметки по доработке

- Формы настроены на приём через Tilda — для самостоятельного хостинга
  нужно переподключить обработчик (Tilda CRM / Telegram / свой бэкенд).
- Часть скриптов/шрифтов могут подгружаться с Tilda CDN (`tildacdn.com`) —
  при полностью автономном размещении их стоит локализовать.
