# ATELIER — сайт студии дизайнерского ремонта

Одностраничный лендинг для студии дизайна интерьеров и ремонта квартир под ключ.
Аналог Tilda-страницы `/remont`, собран на чистом HTML/CSS/JS — без сборки и зависимостей.

## Структура

```
.
├── index.html        # разметка страницы
├── css/styles.css    # стили (адаптив, без фреймворков)
└── js/main.js         # меню, маска телефона, отправка формы
```

## Секции лендинга

1. Шапка с навигацией и кнопкой заявки
2. Hero — заголовок, оффер, статистика
3. Преимущества (фикс. смета, авторский надзор, сроки, гарантия)
4. Услуги (дизайн-проект, ремонт под ключ, комплектация, надзор)
5. Этапы сотрудничества (5 шагов)
6. Портфолио проектов (галерея)
7. Цены — 3 пакета (Дизайн / Под ключ / Премиум)
8. Отзывы клиентов
9. CTA + форма заявки + контакты
10. Подвал

## Запуск

Просто откройте `index.html` в браузере. Или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Что доработать под продакшн

- Заменить плейсхолдеры-градиенты в портфолио на реальные фото проектов.

  (сейчас форма работает в демо-режиме, данные выводятся в консоль).
