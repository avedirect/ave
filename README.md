# тесла · лаборатория — 2026

Концептуальный одностраничный сайт: **Никола Тесла, если бы он вёл бизнес в 2026 году.**
Весь текст — на русском. Тесла «вернулся» не музейным экспонатом, а действующей
лабораторией высокого напряжения и сдаёт электричество как зрелище.

## Что внутри

Каталог продуктов и услуг, которые «продаёт» Тесла в 2026-м:

- **«Гроза-2»** — двухметровая катушка Теслы в аренду для театров и сцен (флагман).
- **Уорденклиф-мини** — беспроводная передача энергии.
- **«Тихий гром»** — молниевое шоу, синхронное с музыкой.
- **Ион-климат**, **Плазма-сфера «Эго»**, **Электро-венец** и прайс-лист
  (беспроводная зарядка, громоотвод как услуга, мастер-класс, аренда лаборатории).

## Дизайн

Реализован по референсу **monopo saigon** — «cinematic darkroom»:

- ахроматичная палитра (только белый / чёрный / оттенки серого), цвет — лишь
  в атмосферной графике (молнии hero и флагмана), никогда в UI;
- единая гарнитура **Inter** (замена Roobert) в экстремальном масштабе —
  от микро-подписей 11px до монументального hero;
- начертание 300 («шёпотный» вес) для всех заголовков;
- чередование белых редакционных секций и чёрных иммерсивных «кадров»;
- pill-кнопки (радиус 75px), тонкие линии-hairline, без теней и скруглений.

## Технически

Один самодостаточный файл **`index.html`** — без сборки и зависимостей.
Внутри: анимация молний на `<canvas>`, reveal-анимации при скролле,
мобильное меню, баннер cookie.

Доступность: семантическая разметка, skip-link, видимый focus, `aria`-подписи,
поддержка `prefers-reduced-motion`, увеличенные тач-таргеты, адаптив без
горизонтального скролла.

## Запуск

```bash
# просто откройте файл
open index.html
# или поднимите локальный сервер
python3 -m http.server 8000   # http://localhost:8000
```

> Шрифты Inter / Raleway подгружаются с Google Fonts — для корректного
> отображения «шёпотного» начертания нужен доступ в интернет; при его
> отсутствии используется системный sans-serif.
