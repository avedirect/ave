# TESLA FUTURE LAB

Кинематографичный одностраничный лендинг о наследии Николы Теслы и технологиях
будущего. Тёмно-синяя «tech / darkroom» эстетика: glass-карточки, свечения,
молнии, частицы-сеть, градиентные цифры, blueprint-фон. Весь текст — на русском.

**Главный файл:** [`index.html`](index.html)

## Секции

1. **Hero / Наследие** — «Человек, который изменил будущее»: портрет, катушка с
   молниями, цитата, лента ключевых фактов.
2. **Путь Николы Теслы** — горизонтальный таймлайн 1856–1943 с анимированной линией.
3. **IDEAS** — «Идеи, которые изменили мир»: 6 изобретений + схема «как рождаются идеи».
4. **IMPOSSIBLE** — «То, что люди говорили Тесле»: лента «это невозможно» 1887→2026 + CTA.
5. **Катушка Теслы** — взрыв-схема устройства с выносками и техническими характеристиками.
6. **Влияние на человечество** — крупные цифры, карта-сеть, 4 сферы влияния.
7. **Tesla Analytics** — дашборд с графиками (ApexCharts) и ключевыми показателями.
8. **Разрез современного города** — изометрическая инфографика с 7 выносками.
9. **Лаборатория будущего** — 3 направления с живыми canvas-визуализациями.

## Анимации — из разных библиотек

Всё подключено **локально** (папка `assets/.../vendor/`) — сайт самодостаточный,
без зависимости от CDN.

| Библиотека | Где используется |
|---|---|
| **GSAP + ScrollTrigger** | parallax, заливка таймлайна, «взрыв» катушки на скролле, reveal заголовков, магнитные кнопки |
| **Lenis** | плавный инерционный скролл |
| **tsParticles** | фон из частиц-сети |
| **anime.js** | рисование линий-выносок и пульс узлов в «разрезе города» |
| **CountUp.js** | анимация всех цифр-счётчиков |
| **Typed.js** | печатная машинка в секции IMPOSSIBLE |
| **ApexCharts** | графики и спарклайны в Tesla Analytics |
| **AOS** | появление карточек при скролле |
| **Splitting.js** | посимвольная анимация белых заголовков |
| **Canvas (свой код)** | молнии, волны аналитики, карта-сеть, виджеты «лаборатории» |

Все анимации уважают `prefers-reduced-motion` и отключаются для пользователей,
предпочитающих покой.

## Замечания по графике

В референсах использованы фотореалистичные 3D-рендеры (катушка, город, портрет).
Здесь они воссозданы **стилизованно** на CSS / SVG / Canvas, чтобы сайт оставался
лёгким и самодостаточным:

- портрет Теслы подгружается с Wikimedia (public domain); если изображение
  недоступно — показывается аккуратный фолбэк-монограмма «NT»;
- катушка, город и «карта мира» — векторные/canvas-стилизации в общем визуальном языке.

Любой из этих элементов легко заменить на готовый рендер, положив картинку в `assets/`.

## Структура

```
index.html              — TESLA FUTURE LAB (главный сайт)
monopo.html             — предыдущая версия (монохромный стиль monopo saigon)
assets/css/style.css    — дизайн-система и все секции
assets/js/app.js        — вся логика анимаций
assets/js/vendor/       — локально подключённые библиотеки
assets/css/vendor/      — стили AOS и Splitting
```

## Запуск

```bash
# локальный сервер (рекомендуется — корректно грузятся локальные ассеты)
python3 -m http.server 8000   # → http://localhost:8000
```

Шрифты Manrope / Inter подгружаются с Google Fonts; при отсутствии интернета
используется системный sans-serif.
