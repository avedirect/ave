# Готовые промпты и шаблоны

Рабочие инструменты: промпты и шаблоны сохранены дословно или близко к оригиналу. Плейсхолдеры в `[квадратных скобках]` заменяй фактурой клиента. Для каждого блока: когда использовать → что подать на вход → сам промпт/шаблон.

## Ключевые принципы

1. **Формула любого промпта: РОЛЬ + ЗАДАЧА + ФОРМАТ РЕЗУЛЬТАТА** (где публикуется, объём, допустимы ли смайлики, куда текст должен привести). Без роли ответ — «среднее мнение интернета».
2. **Сначала контекст, потом задача.** Давай фактуру о бизнесе порциями, проверяй, что ИИ понял, и только потом проси офферы/тексты.
3. **Ограничения прописывай явно** («ни в коем случае нельзя…», «до 56 символов», «без воды»). Огромные файлы путают модель — давай информацию сконцентрированно.
4. **Первый ответ почти никогда не финальный.** Итерируй: «перепиши», «ты взял правильные данные?», «ты учёл вот это?», «переформулируй языком клиента».
5. **Выбирать проще, чем придумывать.** Проси 3–5 вариантов на каждый пункт, отбирай и дорабатывай руками.
6. **ИИ по умолчанию продаёт основной продукт и пишет с водой.** Требуй оффер на простой следующий шаг (расчёт, подбор, план, каталог) и сокращай.
7. **Пошаговый режим для сложных задач:** «3 варианта → стоп → жду „Ок“ → следующий пункт». Так связка собирается без потери качества.
8. **Проверяй факты и галлюцинации.** Ничего не публикуй и не отдавай клиенту без ручной вычитки.
9. **Сначала сделай руками по шаблону, потом отдай шаблон ИИ.** Анализ конкурентов, декомпозиция, чек-листы — ИИ заполняет твою структуру, а не придумывает свою. Скриншоты и прозвоны — только вручную.
10. **Своя формула/эталон > общий запрос.** Загрузи свою формулу оффера или эталонные примеры и требуй ответ строго в этом формате.

## Базовые правила работы с ИИ

### Промпт экспертного уровня (пример: пост психолога)

Плохо: «Напиши пост по теме психологии». Хорошо — роль + контекст о себе + задача + формат:

```
Ты — копирайтер с 10-летним опытом, который пишет крутые вовлекающие продающие посты для блогов психологов в Telegram. Я — клинический психолог, 30 лет, Москва… Твоя задача — написать интересный вовлекающий пост на тему психологии, раскрыть 2 глубокие темы, чтобы психолог мог закрыть на консультацию несколько подписчиков. Формат: пост для Telegram, объём…, по модели AIDA.
```

### «Визитная карточка» бизнеса (старт любого проекта)

Когда: первый контакт с ИИ по новому клиенту, перед ЦА/офферами/контентом.
На вход: закреплённый пост, миссия, описание компании, текущая цель месяца — порциями по 2–3 фрагмента.

```
Шаг 1. Я пришлю информацию о моём проекте. Не отвечай, только анализируй. Твоя задача — уловить суть, ценности и цели моего бизнеса.
[порции фактуры]
Шаг 2. Расскажи, что ты понял о наших ценностях.
[правки: «пункт 3 не про меня, убираем; добавь …» — до точной визитной карточки]
Шаг 3. Дальше в любом порядке: ЦА, конкуренты, боли/желания/страхи/возражения, офферы, контент-план, лид-магниты, воронки.
```

## Анализ ЦА и ниши

### Промпт 0. Описание ниши для второго бота (дословно)

Когда: перед сборкой связки или анализом ЦА, если ниша незнакомая.
На вход: название ниши и её задача.
Выход передай в бота-маркетолога (см. «Маркетинговая связка»).

```
Я хочу, чтобы ты действовал как [эксперт в нише НИША] с двадцатилетним опытом, который специализируется на НИША.
При этом у тебя есть опыт в маркетинге и глубокое понимание своих клиентов.
Ты [эксперт в нише НИША], который помогает клиентам решить [задача ниши НИШИ] и точно знаешь, зачем эти клиенты приходят и что хотят получить от взаимодействия с бизнесом.
Опиши мне, пожалуйста, общими словами свою нишу и чем ты занимаешься, для того чтобы я получил текст, который могу предоставить в другой бот для более глубокого анализа целевой аудитории.
```

### Боли из отзывов и чатов

Когда: есть отзывы (WB, Яндекс Карты, Авито), выгрузка чата, переписки, транскрибации кастдевов.
На вход: сырой текст отзывов/чата.

```
[вставить отзывы / выгрузку чата]
Напиши основные боли, которые пишут люди. Выдели 10 основных и отсортируй по количеству упоминаний.
```

### Пошаговый анализ ЦА по выгрузке Telegram-чата (структура)

На вход: JSON-выгрузка профильного чата. Шаги: определи нишу и спроси подтверждение → психографический анализ → боли и негатив → портрет ЦА с персоной → сегменты → о чём писать каждому сегменту и какие доказательства использовать.

### Проблемы → боли/желания/возражения (цепочка)

Когда: нужна основа для офферов и контент-плана. На вход: визитная карточка бизнеса (см. выше).

```
Напиши 10 проблем, которые решает мой продукт.
→ Добавь ещё 20.
→ Переформулируй языком клиента, более человечно и жизненно.
→ Сделай таблицу: боли / желания / возражения ЦА и как мой продукт закрывает каждое возражение.
```

### Сегменты ЦА и желаемые заявки (выход бота курса «Маркетёр»)

Когда: первое сообщение потенциальному клиенту-бизнесу, подготовка к созвону. Точный текст промпта не приведён, формируй запрос по выходу:

```
Моя ниша: [ниша, регион].
Выдай: сегменты ЦА; истинные желания каждого сегмента; 5 примеров желаемых (хороших) заявок; примеры плохих заявок; правильный этап воронки, на который вести трафик; ключевые смыслы; пример связки; вывод для маркетолога.
```

Вручную допиши: что гарантируешь (N заявок при бюджете X) и какие решения соберёшь.

### Кастдев-интервью

Транскрибации интервью с клиентами (Whisper) → ИИ: «Вытащи боли, смыслы, возражения и офферы под нишу [ниша]».

Сырьё по нише одним запросом: «Ниша: [..]. Дай ответы на 12 вопросов упаковки, 5 офферов, по 3 оффера на каждый сегмент ЦА, почему покупают, боли и возражения, ключевые слова для Директа». Это материал для размышлений — сокращай и дорабатывай руками.

## Маркетинговая связка (11 этапов)

### Как работать

Когда: нужен комплект «этап воронки → ЦА → позиционирование → КЭВ → желание → оффер → дескриптор → CTA → квиз → бонусы → заголовки» для лендинга/квиза и рекламы.
На вход:
- Проект в ChatGPT/Claude с двумя файлами: «Этапы создания связки» (теория 11 этапов) и «Примеры» (эталонные связки, например «Имплантация под ключ» ниже).
- В инструкции проекта — Промпт 1 + Промпт 2 (уточнения).
- В чат: название ниши (лучше — вместе с выходом Промпта 0 и фактурой: КЭВ бизнеса, цифры, опыт, гарантии).

Порядок: ниша → бот выдаёт 3 варианта пункта 1 → правки или «Ок» → … → пункт 11 → резюме. После резюме — Промпт 3 с эталонными офферами.

Правки на шагах (типовые):
- Этап воронки: веди не на большое действие (замер, покупка — 3–5% аудитории), а на входной шаг — подбор, расчёт, план, разбор проекта (до ~50% аудитории). Входной этап бизнес почти всегда уже делает.
- ЦА: выбирай самый «жирный» сегмент, с которым бизнес уже работает; учитывай ситуацию, мотивацию, бюджет, стадию осознанности. Сильно не дроби.
- Истинное желание = микро-задача на сайте («получить план лечения», «отправить снимок и получить мнение эксперта»), а не глобальная мечта.
- Оффер можно длинным, простыми словами; формула: этап + сегмент + позиционирование + КЭВ + желание.
- Если ответ размытый: «подставь цифры: срок, выгода в рублях, опыт, количество проектов».

### Промпт 1. Инструкция для маркетолога (близко к оригиналу)

```
🧭 ИНСТРУКЦИЯ ДЛЯ МАРКЕТОЛОГА (15+ лет опыта)
🧠 РОЛЬ:
Ты маркетолог с 15-летним опытом, который идеально знает сегменты целевой аудитории, этапы воронки продаж бизнеса, идеально создает позиционирование для маркетинговых связок, истинные желания целевой аудитории, владеет всеми формами создания офферов и заголовков, дескрипторов и призывов к действию.
Теория, на которую ты должен опираться — только из файла проекта "Этапы создания связки".
Идеальные примеры, что ты должен выдавать в ответах — из файла "Примеры".

🎯 ШАБЛОН РАБОТЫ
На входе: только название ниши.
На выходе: 3 варианта по каждому из 11 пунктов.
После каждого пункта ты должен остановиться и спросить:
«Подходят ли эти варианты? Если да — напиши ‘Ок’, и я перейду к следующему пункту.»

⚙️ ПОРЯДОК РАБОТЫ
1. Выяснить этап воронки, на который нужен трафик.
Определи, что нужно бизнесу: узнаваемость, заявки, замер, покупка, повторная покупка и т.д.
Дай 3 варианта, где чётко показано, на каком этапе человек сейчас и что нужно сделать, чтобы перевести его на следующий.
✅ Пример формата ответа:
1️⃣ Этап: холодный трафик — человек впервые слышит о компании.
2️⃣ Этап: прогретый трафик — он уже интересовался услугой, но не сделал шаг.
3️⃣ Этап: горячий трафик — готов принять решение, нужен толчок (доверие, бонус, дедлайн).

2. Узнать ЦА, которую мы хотим привести с помощью трафика.
Определи 3 сегмента ЦА, подходящих под этот этап. Каждый вариант должен включать: кто человек, чего хочет и с чем борется.
✅ Пример:
1️⃣ Владельцы частных домов, которые устали от старого фасада и хотят обновить внешний вид.
2️⃣ Семьи, строящие дом впервые и не понимающие, с чего начать.
3️⃣ Люди, у которых есть участок, но они боятся переплатить и попасть на некачественную бригаду.

3. Создать позиционирование для связки.
Сделай 3 формулировки, каждая в 1–2 коротких предложениях. Позиционирование должно показывать: кто вы, что вы делаете и чем отличаетесь.
✅ Пример:
1️⃣ Мы помогаем владельцам частных домов сэкономить до 30% на стройке, не теряя в качестве.
2️⃣ Строим дома «под ключ» за срок, который фиксируется в договоре.
3️⃣ Сервис, где клиент контролирует стройку онлайн и видит каждый этап.

4. Поменять или уточнить КЭВ (ключевое целевое действие).
Сформулируй 3 простых варианта, куда нужно привести человека (например: заявка, консультация, замер, бронирование, звонок).
✅ Пример:
1️⃣ Получить бесплатный расчёт стоимости.
2️⃣ Записаться на замер с инженером.
3️⃣ Забронировать цену на дом под ключ до конца месяца.

5. Выявить истинное желание ЦА под этап воронки.
Определи не поверхностное, а глубинное желание: зачем человек это делает. 3 варианта.
✅ Пример:
1️⃣ Не просто построить дом — а почувствовать себя «на своём месте».
2️⃣ Не просто сэкономить — а не быть обманутым.
3️⃣ Не просто сделать ремонт — а гордиться своим домом перед близкими.

6. Составить оффер под желание ЦА и этап воронки.
Сделай 3 оффера, каждый — конкретное обещание, выгода, срок, доказательство.
✅ Пример:
1️⃣ Рассчитаем стоимость стройки за 15 минут и покажем, где вы можете сэкономить до 20%.
2️⃣ Построим дом под ключ с гарантией в договоре и без скрытых платежей.
3️⃣ Бесплатно подготовим смету и дизайн-план под ваш бюджет.

7. Сформировать дескриптор.
Дай 3 коротких, чётких фразы, которые поясняют суть оффера и усиливают доверие. Формат: «что делаем + для кого + в чём ценность».
✅ Пример:
1️⃣ Помогаем семьям построить надёжный дом без переплат и нервов.
2️⃣ 12 лет опыта. Более 350 реализованных проектов.
3️⃣ Контроль сроков и бюджета на каждом этапе.

8. Сформировать CTA (призыв к действию).
Напиши 3 варианта CTA, каждый в разговорном, простом тоне. Они должны звучать естественно, без давления, но с лёгким побуждением.
✅ Пример:
1️⃣ Узнайте, сколько будет стоить ваш дом.
2️⃣ Получите расчёт прямо сейчас.
3️⃣ Забронируйте скидку до конца недели.

9. Создать квиз под оффер, ЦА и этап воронки.
3 варианта идеи квиза: структура + мотивация пройти. Включи тему, 3–4 вопроса и обещание результата.
✅ Пример:
1️⃣ Квиз «Какой дом подойдёт вам по бюджету и стилю?» — 5 вопросов, результат с расчётом.
2️⃣ Квиз «Сколько вы реально переплачиваете строителям?» — определите скрытые расходы.
3️⃣ Квиз «Подберите проект под свой участок» — получите готовый вариант за 3 минуты.

10. Придумать бонусы.
3 варианта бонусов, которые усиливают оффер и мотивируют к действию.
✅ Пример:
1️⃣ Бесплатный 3D-проект дома.
2️⃣ Гарантия фиксированной цены в договоре.
3️⃣ Авторский дизайн фасада в подарок.

11. Сформировать заголовки для рекламы.
3 коротких, простых заголовка (до 12 слов), цепляющих внимание, отражающих оффер и желание ЦА. Используй эмоцию, выгоду, срочность, результат.
✅ Пример:
1️⃣ «Хотите дом, в котором не будет переделок?»
2️⃣ «Рассчитаем стоимость стройки за 15 минут»
3️⃣ «Успейте забронировать цену на строительство до конца месяца!»

🧩 Формат диалога
Ты пишешь пункт №1 (3 варианта).
Спрашиваешь: «Подходит? Если да — напиши ‘Ок’, и я перейду к пункту 2».
После каждого «Ок» — двигаешься дальше.
После 11-го пункта — делаешь короткое резюме связки (1 абзац).
```

### Промпт 2. Добавление к инструкции (дословно)

Когда: бот выдаёт слишком короткие дескрипторы/CTA и «желания-мечты». Добавь в инструкцию проекта или отправь в чат.

```
Истинное желание ЦА
Здесь мы подбираем истинное желание ЦА в момент, когда она приходит на сайт, чтобы оставить заявку. Следовательно, истинное желание ЦА — это решить какую-то микро-задачу (микро-хотелку) при заходе на сайт: получить план лечения, отправить снимок и получить экспертное мнение.

Дескриптор
Дескриптор должен подталкивать человека к тому, чтобы ответить на вопросы в квизе, который будет дальше, и подчеркивать оффер. Можно его делать в 2-3 предложения и длиннее, чем ты написал. Как пример:
— Получите подробную консультацию, расчет стоимости и бесплатную диагностику Вашего автомобиля от мастера-приемщика с опытом более 8 лет и узнайте, из-за чего именно Ваша АКПП доставляет дискомфорт и способы решения проблемы
— Ответьте на 4 простых вопроса и получите подбор отопления под ключ с выгодой до 600 000 рублей. За 24 часа предложим 3 варианта оборудования именно под Ваш дом от разных производителей по срокам и цене
— Ответьте на 4 простых вопроса и получите подборку автомобилей из наличия в Корее с выгодой до 1 600 000 рублей. За 24 часа предложим 3 варианта автомобилей именно под ваш бюджет и подборку из нашего автосалона в Южной Корее
— Пройдите простой опрос за 2 минуты и получите подборку из 28 террас для частного дома с подробными чертежами и сметами. Расчет на террасу придёт через 45 минут на ваш WhatsApp + менеджер проведет подробную консультацию по террасе

CTA
CTA должен подталкивать человека совершить действие и получить то, что мы обещали ему в оффере и дескрипторе. Можно делать его длинным (3-10 слов) и не бояться прямо призывать к действию. Например:
— Получить 3 варианта отопления с выгодой до 600 000 рублей
— Узнать стоимость ремонта и получить бесплатную диагностику
— Получить подборку авто с выгодой до 1 600 000 рублей

Заголовки и картинки для рекламы
У заголовков есть ограничение – 56 символов (Яндекс.Директ).
Заголовки должны быть чуть кликбейтными и призывать пользователя кликнуть по этой рекламе.
```

### Промпт 3. Адаптация под эталонные офферы (дословно)

## Оффер, дескриптор, CTA, заголовки

### 12 вопросов упаковки (оффер + структура лендинга)

Когда: старт упаковки, интервью с собственником, ТЗ на лендинг. На вход: фактура бизнеса или ответы собственника.

```
Ответь от лица бизнеса кратко и фактами:
1) Что вы продаёте? 2) В чём суть предложения? 3) Почему это должно заинтересовать клиента? 4) Какую проблему решает / почему выгодно? 5) Благодаря чему / как это работает? 6) Чем отличаетесь от конкурентов? 7) Сколько стоит? 8) Почему вам можно доверять (опыт, клиенты, гарантии, цифры)? 9) Что клиенту сделать, чтобы купить? 10) Почему сделать это сейчас?
Дополнительно: кто ЦА; какой бонус/лид-магнит.
Затем собери из ответов спич на 1,5 минуты и структуру лендинга по блокам в этом порядке.
```

Извлечение смыслов: на каждое утверждение собственника задай 2 вопроса — «Почему вы так считаете?» и «Как это можно доказать?» — и перепиши в «факт + доказательство».

### Шаблон оффера (5 полей)

```
Что продаём: ___
Для кого: ___ (бизнес/ниша/сегмент)
Лучший результат: ___ (цифра: ×2 заявок / −X ₽ / N записей)
За какое время: ___
За счёт чего: ___ (опыт N лет, кейс в нише, методика)
→ «[Услуга] под ключ для [ниша]. [Опыт N лет]. [Результат] в течение [срок] — или вернём деньги».
```

Проверка: прочитай как «Я делаю так, чтобы…». Варианты 1/2/3 — в ту же таблицу (лист «Оффер»; дальше — наполнение «обязательно / дополнительно / плюшки» и тарифы База / Улучшенный / VIP).

### Генерация 5 офферов (4U + следующий шаг)

Когда: нужны варианты оффера для лендинга/квиза. На вход: 5 полей выше.

```
Ниша: … Что продаём: … Для кого: … Лучший результат: … За какое время: … С помощью чего: …
Напиши 5 офферов по 4U (полезность, уникальность, ультраспецифичность, срочность) и по формуле "продукт + ключевая выгода + факты". Оффер должен продавать не основную услугу, а простой следующий шаг (консультация/подбор/каталог/расчёт). Без воды, с конкретными цифрами.
```

Если у тебя своя формула оффера — загрузи её: «Дай 5 вариантов строго в этом формате».

### Позиционирование: шаблоны

- Компания: «<Название> — это <категория> для <ЦА>, которая <основная задача> посредством <уникальность>».
- Маркетолог/агентство: «Я делаю так, что [компании/бригады ниши] начинают получать заказы от [золотой клиент: ситуация (ключи на руках) + бюджет (от X млн) + готовность (договор в течение 30–60 дней)]». Промпт: «Ниша: … Сегмент: … Желаемые заявки: … Дай 5 вариантов „Я делаю так, что…“».
- Лайнер: «[Проблема ЦА одной фразой]. [Компания] [решение простыми словами], и тогда [конкретный результат/чувство клиента]». Проверка: звучит вслух, запоминается, никто не спрашивает «что это значит?».

### Цена неизвестна до выезда

```
[Услуга] в чистом виде стоит [X] ₽. Если понадобится [доп. работа 1 / 2 / 3], цена будет выше, мастер на месте назовёт её до начала работ, и вы вправе отказаться.
```

### Правила для дескриптора, CTA и заголовков (для проверки ответа ИИ)

- Дескриптор дополняет оффер и подводит к квизу: 2–3 предложения, «Ответьте на N простых вопросов и получите [что] [выгода]. За [срок] предложим [N вариантов] [под что]».
- CTA = то, что обещано в оффере, прямо на кнопке, 3–10 слов. Не «Отправить»/«Узнать подробнее». Конверсия с таких CTA в примерах автора ~7%.
- Заголовок рекламы = ниша + часть оффера из лендинга; до 56 символов; чуть кликбейтный. Цены — в доп. элементы.
### Генератор текстов блоков лендинга

```
Ниша: [ниша]. Для каждого блока шаблона лендинга (первый экран, поп-ап, преимущества, портфолио, квиз, консультация, форма) предложи заголовок, подзаголовок, 3 буллета и CTA. Пример для портфолио: название проекта + описание + объём поставки.
```

Быстрый вариант: «Напиши яркое описание продукта на мой сайт для [ниша], которое заинтересует потенциальных покупателей менее чем за 40 секунд». Результат обязательно дорабатывай.

### Поиск незакрытых возражений на лендинге

Когда: аудит сайта, низкая конверсия. На вход: текст или скриншоты страницы (или PDF через Ctrl+P).

```
Вот текст/скриншоты страницы [вставить]. Представь, что ты [целевая аудитория]. Озвучь, что ты подумаешь, изучая этот сайт, какие у тебя возникнут возражения и какие из них на странице не закрыты.
```

Дальше: «Выпиши 5 самых частых причин отказа → на каждую ответ в 2 предложения → сведи в один абзац для блока „Почему нам доверяют“».

## Квиз

Когда: оформление заявки почти в любой нише (кроме срочных, где сразу закрывают на звонок).
На вход: оффер, сегмент, КЭВ, дескриптор из связки.

Правила (проверяй по ним вывод ИИ):
- Вопросы — потребительские, на которые человек отвечает за 3–5 секунд, не задумываясь (то, что он уже знает).
- Не спрашивай бюджет, коэффициенты, технические параметры; сроки часто игнорируют.
- 3–5 вопросов + обещание конкретного результата (что, от кого, за какой срок, куда придёт).
- Дескриптор перед квизом: «Ответьте на 4 простых вопроса и получите…».

Промпт (собран по правилам урока):

```
Ниша: [ниша]. Сегмент ЦА: [кто, ситуация]. Оффер: [оффер]. КЭВ: [входной шаг].
Предложи 3 идеи квиза: тема-заголовок, 3–4 вопроса с вариантами ответов, обещание результата (что получит, от кого, за какой срок и в каком канале).
Вопросы — только потребительские, на которые человек ответит за 3–5 секунд, не задумываясь. Не спрашивай бюджет, коэффициенты, технические параметры.
Добавь дескриптор перед квизом (2–3 предложения, начинается с «Ответьте на N простых вопросов и получите…») и CTA кнопки 3–10 слов, повторяющий обещание.
```

Пример вывода:

```
Квиз «Какой вариант имплантации подойдёт именно вам?»
– Где отсутствует зуб?
– Есть ли снимок или план лечения?
– Что важнее — срок, комфорт или цена?
– Как давно ходите без зуба?
📩 Результат: расчёт и 2–3 варианта лечения от врача за 1 день.
```

## Объявления

### Текст поискового объявления

```
[Акция!/Внимание!/Подарок!] [Ключ] [от ЦЕНА руб.]. [Гарантия/Доставка/Монтаж под ключ]. [Призыв: «Посчитаем бесплатно за 5 минут» / «Будем у вас через час»]
```

Лимит — 81 символ без учёта знаков препинания. Вариант «акция + формула цены» (дословно):

```
Акция на {товар}! {Материал} + установка = от {цена} ₽/м + гар. {N} лет. Рассчитаем за 3 минуты
```

В лимит укладывай, сокращая точки и слово «гарантия». В текст можно вставлять часть дескриптора («Получите…») и усилители: замер = 0 ₽, срок = 1 день, гарантия = 5 лет.

### Пара заголовков

```
З1 = [1–3 слова ключа из названия группы, с заглавной, предлоги строчные]!
З2 = [от ЦЕНА руб. | Регион | Акция | Модель]
```

- Каждое слово ключа и города — с заглавной, кроме предлогов; «цена» → «от N руб»; «!» в конце З1, если влезает.
- З2 готовь в нескольких длинах (~28/25/20 символов) — генератор подставит самый длинный влезающий. Пример (заборы из сетки): «от 500 руб/м² • Выезд на замер • Приступим завтра».
- Общая ширина ≤ ~536 px: проверь в превью, что З2 не обрезан.

### Уточнения

```
[Наличие/Под заказ] · [Опыт N лет] · [Бесплатная доставка при заказе от X руб.] · [Гарантия/Договор/Скидка до N%]
```

Не меньше 4 уточнений; каждое — кусок связного предложения.

### Комбинаторика для генератора

Список 1 «Ремонт окон» × список 2 «станции метро» → ключ «[Метро] ремонт окон», объявление «#Метро# ремонт окон — выезд 0 ₽, за 20 минут». Так же — города МО в радиусе 10 км.

### Креатив для РСЯ через ChatGPT

На вход: скриншот первого экрана лендинга + оффер + дескриптор + фото объекта.
```
Сделай рекламный креатив по этому экрану: оффер [..], дескриптор [..]. Логотип и иконку убери, на фон — [навес/террасу], кнопки не убирай. Текст — не больше 20% площади.
```

## Аудит звонков отдела продаж ИИ-чек-листом

Когда: заявки есть, продаж мало; споры «плохие лиды vs плохие продажи»; нужно обновить скрипт.
На вход: транскрибации звонков (от 10–20 для аудита, 40–60 для сборки скрипта), итоги звонков из CRM, при наличии — данные сквозной аналитики.

### Промпт аудита (близко к оригиналу)

```
Вот транскрибации звонков отдела продаж компании [ниша]. Проанализируй, как менеджеры продают и что нужно улучшить. По каждому звонку проставь по чек-листу ✓/✗: приветствие и представление, выявление потребности, презентация, отработка возражений, назначение следующего шага/закрытие. В конце — сводка типовых ошибок и рекомендации по скрипту.
```

Расширенный чек-лист (добавь к промпту, если нужна детализация):

```
1. Приветствие с именем, представился, назвал компанию.
2. Программирование разговора («Давайте поступим так… в любом случае мы с вами договоримся, идёт?»).
3. На «сколько стоит?» не назвал голую цену, а перевёл в квалификацию.
4. Квалификация: потребность → срочность → бюджет («Я просто почему спрашиваю…»).
5. Боль: «А ещё что?», усиление (как давно / как решали / какой результат).
6. Подытожил словами клиента.
7. Закрыл на КЭВ (замер, расчёт, визит) с оффером и подарком; назначил дату/время.
8. На «подумаю» — отработал, а не отпустил.
9. Скорость перезвона по заявке; повторный контакт.
Для каждого менеджера — итоговый балл и 3 главные ошибки.
```

```
Вот расшифровки 40–60 реальных звонков отдела продаж [ниша]. Составь структурированный скрипт продаж по этапам (первый контакт, квалификация, презентация, ключевой этап, возражения, дожим), список частых вопросов с лучшими ответами, точки, где клиент готов купить, и анкету квалификации.
```


## Редактура продающего текста

### Чек-лист-промпт (по Ильяхову)

Когда: любой текст сайта, КП, объявления, поста перед публикацией. На вход: текст + факты о компании (цифры, сроки, материалы, клиенты).

```
Перепиши текст:
1) убери вводные слова, усилители и оценки («качественный», «лучший», «максимально», «уникальный», «индивидуальный подход», «команда профессионалов»);
2) каждую оценку замени фактом (число, срок, материал, условие, имя клиента) или сценарием «кому и в какой ситуации это полезно»;
3) «более/около/различные/некоторые» замени точными данными или перечнем;
4) отглагольные существительные и страдательный залог перепиши глаголами в действительном залоге;
5) в каждом блоке — действующее лицо и действие;
6) в начале каждого абзаца — суть;
7) проверь тест «закрой название компании» — текст не должен подходить любой фирме.
```

### Шаблоны блоков сайта

- **О компании:** [Название] — [понятная категория] (+ для кого) → чем занимаемся простыми словами + польза → ответы на вопросы клиента по формуле «Мы делаем так, поэтому вы получаете…» → CTA «Чтобы [результат], [действие] — [контакт]».
- **О специалисте:** «[Имя], [профессия]. [1–3 вида работ] для [кого]. [Вопрос клиента]? — [ответ + доказательство]. [Честное ограничение и что даю взамен]. Чтобы [записаться], [контакт]».
- **План из 3 шагов:** «[Глагол-шаг] — [1–2 предложения о пользе шага для клиента]».

Самопроверка КП/презентации: «Вот моя презентация (PDF). Скажи плюсы, скажи минусы, скажи, что можно улучшить».

## Таблица декомпозиции ниши

Когда: перед запуском — проверить, сходится ли экономика и хватает ли спроса; обосновать бюджет клиенту.
На вход: цель по доходу, маржинальность, средний чек (из анализа конкурентов), конверсии, частоты горячих масок из Вордстата, прогноз цены клика.

Google-таблица: строки — формулы, руками вписывай только входные значения, формулы растягивай. Цель — «поиграться с цифрами»; отклонение от реальности обычно ≤ ~10%.

```
1. Цель: доход в месяц (реалистичный максимум для региона).
2. Партнёры (с кем делите прибыль): ×1 / ×2 / ×3.
3. Прибыль с единицы ИЛИ маржинальность/агентские, % (обычно 10%).
4. Оборот = Цель × Партнёры / Маржинальность.
5. Средний чек (с допродажами) — из анализа конкурентов; ориентир 20–300 тыс.
6. Количество продаж = Оборот / Средний чек (идеал 1–40; если сотни — нужен отдел продаж).
7. Предоплаты (если непонятно — ×1).
8. Выезды/замеры/расчёты = Продажи / конверсия закрытия (0,2–0,7; по умолчанию 0,3).
9. Заявки/звонки = Выезды / конверсия заявки в замер (0,2–0,6; без замера — 1 или 0,9).
10. Переходы = Заявки / конверсия сайта (0,05–0,15; считай вилку 1/3/5/10%).
11. Показы на поиске = Переходы / CTR (худший случай 10%; горячие запросы 10–25%).
12. Сумма частот горячих масок из Вордстата — должна быть ≥ п. 11, иначе снижай цель или меняй нишу.
13. Средняя прогнозная цена клика — «Прогноз бюджета» в Директе (берите среднее списываемое).
14. Бюджет = Переходы × CPC.
15. Проверка: максимальная стоимость клиента > фактической (Бюджет / Продажи).
```

Пример: 1 500 кликов × 30 ₽ = 45 000 ₽ рекламы, чтобы заработать 100 000 ₽. НДС не учитывай.

Обратная воронка (лимиты):

```
Макс. цена клиента = чистая прибыль с заказа / (2…5)   (новичкам — 1/2–1/3 прибыли)
Макс. CPL = Макс. цена клиента × CR(лид → продажа)
Макс. CPC = Макс. CPL × CR(сайт)
```

В нишах с растянутыми платежами (стройка) и с LTV (опт) можно отдать почти всю прибыль первой транзакции. Рекламу веди отдельной статьёй расходов.

Аргумент для собственника, который хочет «только заявки на замер»: «Заявки на замер — 10–20 в месяц по 5 000 ₽. Заявки на подбор вариантов — 100–150 по 800 ₽, и люди уже познакомились с компанией».

## Прочие шаблоны для работы с клиентами директолога

- **Убедить поднять бюджет:** «Напиши убедительный спич / сопроводительное письмо собственнику бизнеса, чтобы убедить его увеличить рекламный бюджет. Исходные цифры: потратили [X], получили выручку [Y], маржинальность [Z], цена заявки [..], конверсия в продажу [..]».
- **КП:** загрузи в Claude шаблон своего КП + фактуру клиента (ниша, бюджет, задачи) → черновик КП.
- **Объявление на Авито о своей услуге:** «Составь продающий текст объявления на Авито для услуги [настройка Яндекс Директа], с триггерами и цепляющими элементами. Вот структура объявления конкурента [вставить] — сделай рерайт, не копируя».
- **Тренер переписки:** бот спрашивает нишу, тип бизнеса, гео, бюджет; играет клиента, избегающего записи на аудит; в конце — оценка /10 и что усилить. Цель ≥ 7/10.
- **Бот ассоциаций:** «Придумай мне ассоциацию на то, когда человек оставляет заявку, но ему не звонят» → 2 бытовые аналогии для объяснения клиенту.
