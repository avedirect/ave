# Yoast → зелёные светофоры (CPT `articles`)

Цель: **SEO = зелёный**, **Readability = зелёный**. Это две независимые проверки.
Светофоры ≠ ранжирование Google/Яндекса, но это рабочий чеклист качества сниппета и текста.

Сайт: Yoast SEO Premium (orphaned content, internal linking).  
Эталон зелёного: `chastaya-pravka-sbrasyvaet-obuchenie-strategii` (ключ `обучение стратегии`).

---

## SEO vs Readability

| | **SEO analysis** | **Readability analysis** |
|---|---|---|
| О чём | Ключевая фраза + сниппет + ссылки + длина + alt | Как легко читать текст человеку |
| Красный | Нет/плохо стоит focus keyphrase, ключ не в title/meta/H1/первом абзаце, плотность, ссылки, alt, длина | Длинные предложения/абзацы, мало переходных слов, много пассива, подряд H2 без текста |
| Серый | Анализ не посчитан (импорт/массовая правка без открытия записи) или ключ «битый» | То же |
| Orphaned (Premium) | Отдельный индикатор: **0 входящих** внутренних ссылок | Не влияет на readability |

**Почему «написали SEO-текст», а красный:** чаще всего заполнены только SEO Title + Meta Description через Bulk Editor, а **Focus Keyphrase пустой**. Без ключа Yoast почти все SEO-проверки красит в красный, даже при хорошем тексте.

## Полный чеклист SEO → зелёный (маппинг на шаблон AVE Direct)

Статусы Yoast: 🟢 good / 🟠 OK / 🔴 bad. Цель — все критичные 🟢, остальные не 🔴.

### A. Focus keyphrase (обязательно первым)

1. **Задать Focus keyphrase** в сайдбаре Yoast (или при публикации агентом — не оставлять пустым).
2. Правила для русского:
   - 2–4 слова, именительный падеж, как ищут люди.
   - Не копировать весь H1.
   - Одна основная фраза на статью; синонимы — в тексте, не вторым «главным» ключом без нужды.
   - Примеры: `обучение стратегии`, `слабый оффер`, `дешёвый клик`, `цель в Директе`, `РОП отдела продаж`.
   - Плохо: `Собственник как каменная стена для команды` (это заголовок, не запрос).

### B. Где должен встретиться ключ

| Проверка Yoast | Куда в шаблоне | Как сделать |
|---|---|---|
| Keyphrase in SEO title | Yoast SEO Title | Ключ ближе к началу: `{Ключ}: {выгода/конфликт} \| AVE Direct` |
| Keyphrase in meta description | Yoast Meta Description | Первое или второе предложение; 140–160 симв. |
| Keyphrase in introduction | Вступление + **Коротко** | Первые 40–60 слов и строка «Коротко: …» содержат ключ или точную словоформу |
| Keyphrase in subheading(s) | минимум 1–2 **H2** | Напр. «Почему обучение стратегии ломается…» |
| Keyphrase density | весь body | ориентир **0,5–2,5%** (у эталона ~1,1% / 8 вхождений на ~700 слов); не спамить |
| Keyphrase in image alt | alt обложки `ave-direct-article-cover` | Описательный alt с ключом, не = голый H1 |
| Keyphrase in slug | permalink | Транслит ключевых слов; не раздувать |
| Text length | body | ≥ **300** слов минимум; для AVE Direct цель **600–900** (эталон ~700) |
| Outbound links | 1+ внешняя (справ./справка Директа) по желанию | Не обязательна для зелёного, но помогает |
| Internal links | ≥ **2** исходящих на другие `articles` / услуги | Блок после «Типичные ошибки» или в абзацах; чинит и orphan у целей |
| Incoming links / Orphaned | с **других** статей | См. план orphaned ниже — на светофор SEO статьи влияет слабо, на Premium-фильтр «Бесхозный» — да |
| Cornerstone | только хабы | Не включать на каждую короткую статью |

### C. Сниппет (уже часто зелёный через Bulk)

- SEO Title ≤ ~60–65 симв. видимых; без длинного `%%sitename%%`-слогана.
- Meta Description уникальная, с ответом на интент; не «заголовок + слоган агентства».
- API: `POST /wp-json/yoast/v1/bulk_editor/update_search` (title + description).  
  **Focus keyphrase этим API не ставится** — только в редакторе записи (поле Yoast) или через post meta `_yoast_wpseo_focuskw` (если зарегистрируете в REST).

## Полный чеклист Readability → зелёный (без «детского» тона)

Yoast Readability на русском строже к длине предложений и «transition words». Сохраняем экспертный тон AVE Direct.

| Проверка | Правило | Практика в шаблоне |
|---|---|---|
| Sentence length | большинство предложений **≤ 20 слов** | Одна мысль — одно предложение. Длинный тезис → точка + короткое следствие. |
| Paragraph length | абзацы **≤ ~150 слов**, лучше 2–4 предложения | Не стены текста под H2 |
| Subheading distribution | текст между H2, не H2 подряд | Шаблон: H2 → прямой ответ (1 предлож.) → 1–2 абзаца |
| Transition words | ≥ ~30% предложений с связками | «поэтому», «если», «сначала», «затем», «например», «в итоге», «с другой стороны», «кроме того» |
| Passive voice | мало страдательного залога | «Алгоритм ищет…», не «ищется алгоритмом…» |
| Consecutive sentences | не начинать 3+ подряд одним словом | Разнообразить зачины |
| Flesch / RU | ориентир «достаточно простой» | Короткие предложения важнее «разговорности» |

**Не делать:** упрощать до кликбейта, выкидывать термины Директа, дробить каждую фразу до 5 слов.

**Шаблонный ввод, который бьёт readability:**  
`«{H1} — практический материал о том…»` + склейка H2 с абзацем без перевода строки. Убрать шаблонную простыню; сразу прямой ответ + **Коротко**.

## Почему красный / серый прямо сейчас

1. **Красные маркетинговые** (оффер, клик, цель): текст и meta уже «SEO-готовые», но **`focus_keyphrase` = ""`** → SEO красный. Readability красный часто из‑за шаблонного длинного вступления и/или недостатка transition words / длины предложений в отдельных абзацах.
2. **Серые «Школа управления»**: ключ часто = весь заголовок; нет **Коротко** и **FAQ**; анализ мог не пересчитаться после массовой проставки meta; почти все **orphaned** (0 входящих).
3. **2662 Orphaned**: нет входящих внутренних ссылок. Premium помечает отдельно от цвета SEO.

## Playbook для автора / агента (повторяемый)

### 1) Перед написанием
- Выбрать **focus keyphrase** (2–4 слова).
- Сформулировать SEO Title и Description **с этим ключом**.
- Список 2–4 URL для перелинковки (соседние статьи темы + 1 услуга/хаб).

### 2) Собрать тело по шаблону
1. Вступление: прямой ответ, ключ в первом абзаце.  
2. `<p><strong>Коротко:</strong> …</p>` с ключом/цифрами.  
3. H2-блоки; **первое предложение = ответ**; ключ в 1–2 H2.  
4. Середина: cover + alt с ключом + CTA медиаплана.  
5. ≥2 internal links.  
6. `[banner]` перед выводом.  
7. FAQ (3–4) + Вывод + мягкий CTA.

### 3) В Yoast перед Publish / Update
- Вписать Focus keyphrase.  
- Проверить SEO-список → устранить красные.  
- Проверить Readability → укоротить предложения, добавить связки.  
- Сохранить ещё раз, если светофор серый после импорта.

### 4) После публикации (orphaned)
- С 2–3 уже трафиковых/соседних статей добавить ссылку на новую (анкор = ключ или естественная фраза).  
- Кластеры: Директ ↔ Директ, Школа управления ↔ продажи/РОП.  
- Не ссылаться со всех 2700 сразу: приоритет свежие + cornerstone/хабы + статьи того же кластера.

## План Orphaned content (2662)

1. **Не пытаться закрыть всё сразу.** Приоритет: новые статьи 2026 → рубрика Яндекс Директ/Маркетинг → топ по трафику/лидам.  
2. В каждой новой/переписанной статье — **≥2 исходящих**; в 2 соседних старых — **по 1 входящей** на новую.  
3. Хабы (cornerstone): «обучение стратегии», медиаплан, аудит — собирать входящие и раздавать исходящие на кластер.  
4. Раз в спринт: фильтр Yoast «Бесхозный контент» → взять 20 URL → проставить ссылки из ближайших по теме.  
5. Школа управления: перелинковка внутри `/blog/prodazhi/` + мост 1–2 ссылками из маркетинговых статей про отдел продаж/лиды.

## Быстрый «дозеленить» уже написанные red

Для `slabyj-offer`, `deshevyj-klik`, `odna-cel` и аналогов:

1. Поставить focus keyphrase (напр. `слабый оффер` / `дешёвый клик` / `цель в Директе`).  
2. Убедиться, что ключ есть в SEO title, description, первом абзаце, ≥1 H2, alt обложки.  
3. Добавить 1–2 internal links, если 0–1.  
4. Укоротить вступление (убрать «практический материал о том…»), добавить 4–6 связок.  
5. Update → дождаться пересчёта светофоров.
