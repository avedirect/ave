# Сайт практикума «Связка: сайт + Яндекс Директ»

Статический сайт на Python-генераторе: `src/` + `static/` → `public/`. Фреймворков нет, нужен только Python 3.11+.

## Команды

```bash
python build.py     # собрать сайт в public/
python pack.py      # собрать и упаковать в ../releases/site-vN-ГГГГ-ММ-ДД.zip
python -m http.server 8766 --directory public    # посмотреть в браузере
```

После `build.py` в конце выводится список того, что осталось подставить (даты, цены, контакты, счётчик).

## Где что лежит

```
build.py                     — сборщик. Весь текст, который меняется, — в начале файла:
                               SITE (адрес, контакты, реквизиты, счётчик Метрики),
                               COURSE (дата старта, недели, места, созвоны),
                               TARIFFS (три тарифа и цены),
                               MODULES (8 модулей программы),
                               PAINS / LAB / STEPS / COMPARE (блоки главной)
src/pages/*.body.html        — тексты страниц. Метки вида <!--MODULES-->, <!--QUIZ-->, <!--TARIFFS-->
                               заменяются сборкой; {{start}}, {{phone}}, {{icon-tg}} — подстановки
src/pages/*.faq.json         — вопросы и ответы страницы: [["вопрос", "<p>ответ</p>"], ...]
src/articles/NN_slug.html    — статьи блога: <!--META {json}--> + HTML-текст
src/sprite.svg               — все иконки сайта (один файл)
static/assets/css/site.css   — базовые стили движка
static/assets/css/pages.css  — внутренние страницы, шапка, подвал, плавающее меню
static/assets/css/course.css — блоки этого сайта: модули, тарифы, схема связки, вкладки
static/assets/js/site.js     — квиз, маски, отправка форм, окна, цели Метрики
static/send.php              — приём заявок: почта + Telegram + leads.log (настроить константы вверху)
```

## Что сделать перед публикацией

1. В `build.py` заполнить всё, что выводится списком после сборки (даты, цены, места, контакты).
2. Вписать номер счётчика в `SITE['metrika']` — код Метрики и цели подключатся сами.
3. В `static/send.php` указать `MAIL_TO`, `MAIL_FROM`, токен бота и chat_id.
4. Если сайт поедет на поддомен или в папку — поправить `SITE['url']` (от него зависят canonical, sitemap, Open Graph).
5. Пересобрать: `python pack.py`, загрузить содержимое архива в `public_html` на хостинге.
6. После публикации: создать цели в Метрике (список — в комментарии в `site.js`), отправить `sitemap.xml` в Яндекс Вебмастер, проверить тестовую заявку.

## Фотографий на сайте нет

Все иллюстрации — градиенты и SVG: схема связки, карточки проблем, обложки статей. Так сайт выглядит цельно без фотосъёмки. Когда появятся фото (портрет автора, скриншоты кабинета, кадры с созвонов) — их можно добавить в `static/img/` и подставить в блоки.
